# Components of a Program
// comment - single line comments in C++
/* block comment */ - multiline comments in C++
#include <iotstream> - (#)Directives for the Preprocessor
                        Directive tells the preprocessor to include the iotstream file
using namespace std; - All elements of the standard library have namespace.
int main() - main function where program execution starts
cout <<"Hello World">> - Statement that produces some effect.
                        cout represents the standard output stream.
return 0; - marks the termination of the program.
