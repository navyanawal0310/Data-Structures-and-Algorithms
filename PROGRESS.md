## Mastery Rule

A topic is not considered mastered simply because the examples were completed.

A topic is considered mastered when I can:

1. Explain the concept.
2. Implement it without reference.
3. Solve basic problems using it.
4. Analyze its complexity.
5. Handle common edge cases.
6. Reproduce the solution after a gap in time.
