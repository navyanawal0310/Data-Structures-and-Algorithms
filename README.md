# Data Structures & Algorithms

Personal repository for learning **C++**, Data Structures & Algorithms, and preparing for technical interviews and placements.

The goal is to develop the ability to:

* Understand a problem
* Identify the underlying pattern
* Design an algorithm
* Analyze time and space complexity
* Implement the solution in C++
* Debug and improve the solution
* Explain the solution clearly in an interview
* Reproduce the solution without looking at previous code

## Interview Preparation

After completing the fundamentals, problems will be practiced in three modes:

### Learning Mode

Problems are selected specifically to teach a concept or pattern.

### Revision Mode

Previously solved problems are attempted again without looking at the original solution.

### Interview Mode

Random problems are attempted under time constraints without knowing the topic beforehand.
